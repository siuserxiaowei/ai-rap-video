# Estimate Cost

Copy page

POST

https://api.sync.so/v2/generations/estimate

POST

/v2/generations/estimate

cURL

curl -X POST https://api.sync.so/v2/generations/estimate \

 -H "x-api-key: <apiKey>" \

 -H "Content-Type: application/json" \

 -d '{

 "model": "model",

 "duration": 1.1

}'

Try it

200 Successful

{

 "estimatedFrameCount": 1.1,

 "estimatedGenerationCost": 1.1,

 "estimatedCredits": 1.1

}

Estimate a generation from its model and billable duration in seconds. Supply a finite positive duration and, optionally, a finite positive fps (defaults to 30). No media is fetched and no generation is created. POST /v2/generate/estimate-cost is an alias of this endpoint. Invalid request fields return 400. If the billing calculation rejects the duration or frame rate, it returns 422 cost_estimate_unavailable without price fields.

### Authentication

x-api-key string

API Key authentication via header

### Request

This endpoint expects an object.

model string Required

Model to estimate, for example lipsync-2 or sync-3.

duration double Required

Finite, positive billable duration in seconds.

fps double Optional

Finite, positive frame rate. Defaults to 30.

reasoningEnabled boolean Optional

Include reasoning pricing when supported by the model.

### Response

A single estimate; estimatedCredits is null for dollar-billed organizations.

estimatedFrameCount double

The estimated frame count for the generation.

estimatedGenerationCost double

The estimated cost of the generation in USD.

estimatedCredits double or null

Estimated credits for credit-billed organizations; null for dollar-billed organizations.

### Errors

400

Bad Request Error

401

Unauthorized Error

422

Unprocessable Entity Error

500

Internal Server Error
