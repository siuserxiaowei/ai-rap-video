- 集成：https://openart.ai/mcp/ 。公开 MCP（Streamable HTTP + OAuth）与 CLI，图像/视频、Smart Shot、参考素材及项目管理可用，共用账户点数；Character 标为路线图。未核实通用 REST API 或 Director 音乐视频 API。

证据保存在 `research/evidence/24/`。价格为抓取时动态促销文本；音轨上传格式、长度、口型精度和 Director 消耗仍待核。
