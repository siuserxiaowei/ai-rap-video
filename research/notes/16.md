# Pollo AI 核查笔记

核查日期：2026-10-23。使用 agent-reach 的 Jina Reader；首页复用父任务提供的完整快照，后续读取首页已有的口型、价格和 API 链接，并从 API 入口读取文档。所有原始全文保存在 evidence/16/。不登录、不付费、不生成。

## 结论

Pollo AI 是多模型图像/视频聚合创作平台。首页列 Veo、Sora、Kling 等以及 Music Video 应用入口，但入口不能证明端到端 Rap 创作。口型页明确流程为视频加预录音频或文字转语音，再处理并下载；未发现 Rap 原声、押韵、伴奏创作的具体证据。

## 口型边界

官网称支持声音库、多语言和动态头部口型。FAQ 规定音频最大20MB、最长30秒；视频为 MP4/MOV、最大100MB、至少720p，步骤建议清晰正面脸。FAQ 明确当前不直接接收图片。所有准确度、速度和隐私承诺都是供应商声明，未实测。

## 积分与价格

Free 对比表写20积分；Lite/Pro/Ultra 分别每月400/800/5000积分。页面卡片标 Billed annually，但 Lite/Pro/Ultra 显示$15/$29/$129每月；Annual比较表却为$12/$14.50/$99每月。保留冲突，不选其中一个当成交价，也不当逐月订阅价。扣分取决于模型、工具、时长、数量与分辨率，未找到口型单次扣分。FAQ说订阅积分不结转；附加积分不失效、不退款。

## API

官方 api.pollo.ai 有多模型 API 介绍、独立价格链接及 docs.pollo.ai 文档入口。文档正文说明认证、视频/图像任务和回调，导航包括任务状态与积分。因此记 documented；未确认口型或Rap专用 API，不能把网页工具自动视为 API 覆盖。

## 产品启示（推断）

模型聚合提供素材生产广度；Rap产品仍需明确歌曲生成、人物素材和口型对齐的完整链路。30秒限制可能使整曲流程需要分段；当前未验证自动拼接。定价冲突提示任务提交前展示积分和预计产物的重要性。
