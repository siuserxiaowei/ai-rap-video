# 34 — Suno

核查日期：2026-10-23；只读公开官网和帮助正文，未注册、生成、付款或实测。

Suno 是音乐创作工具。官网支持用曲风、情绪、主题或自己的歌词生成含人声、器乐和制作的歌曲，也列出 Remix、分轨和浏览器 Studio。**推断**：Rap 歌词可作为歌词输入，适合作为 Rap 视频流程的音乐前段；中文咬字、flow、押韵执行、人物口型和视频生成均未验证。

当前[价格页](https://suno.com/pricing)：Free 每天50 credits，无商用权、无每月歌曲下载。Pro 年付折月 $8、2500 credits/月、20次下载/月；Premier 年付折月 $24、10000 credits/月、60次下载/月。不要与逐月付费混同。首页 FAQ 仍列 $10/$30 的逐月价格及旧模型细节，存在同步差异，未当作当前套餐权威价格。

[免费权利帮助](https://help.suno.com/en/articles/9601601)：免费歌仅个人非商业用途，不能变现，可通过 Suno 链接分享。[付费权利帮助](https://help.suno.com/en/articles/9601665)当前明确“订阅期间下载”的歌曲获商业使用权，可用于流媒体、影视、游戏或独立销售；Suno 不分取收益。商业权利不保证版权保护。首页泛称付费创作歌曲可商用，采用帮助页更具体的下载条件。未在本次范围全面审读服务条款。

API：官网／帮助中心和官方域名文档搜索未找到公开生成 API 文档，记录 `not_found`；第三方 Suno API 不作为官方能力。
