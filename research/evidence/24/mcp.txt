## Connect OpenArt to ChatGPT

1
### Open Plugins in ChatGPT

[Add OpenArt plugin](https://chatgpt.com/plugins/plugin_asdk_app_6a42dbbe74c081918a592a0aad65ca26) directly, or go to [chatgpt.com/plugins](https://chatgpt.com/plugins) and search for OpenArt.

2
### Install and sign in

Click **Install Plugin**, then **Sign in with OpenArt**.

3
### Start creating

Type **@OpenArt** in any chat and describe what you want.

[Create Images & Videos in ChatGPT](https://chatgpt.com/?prompt=%40OpenArt+Create+a+polished+beauty+commercial+featuring+this+model+and+product.)

[Video 63](https://openart.ai/mcp/)

## Connect OpenArt to Claude

1
### Go to Claude → Customize

In Claude desktop or [claude.ai](https://claude.ai/new#customize/connectors), go to **Customize → Connectors**.

2
### Add custom connector

Name it **OpenArt** and paste the link:`https://mcp.openart.ai/mcp`

3
### Connect and sign in

Click **Add → Connect**, sign in with your OpenArt account. Then ask Claude to make an ad video.

[Open Claude connectors](https://claude.ai/new#customize/connectors)

[Video 64](https://openart.ai/mcp/)

## Connect OpenArt to Cursor

1
### Open Cursor MCP settings

For team setup, open [Plugins & MCPs](https://cursor.com/dashboard/plugins) in your Cursor dashboard and sign in. For local setup, open **Cursor settings → Tools & MCP** in the desktop app.

2
### Add the MCP server

Add a new MCP server named **OpenArt** using this URL. If Cursor opens **mcp.json**, add it as the server’s **url**:`https://mcp.openart.ai/mcp`

3
### Connect once

Click **Connect** next to the OpenArt MCP server and sign in with your OpenArt account. Then ask Cursor to make an ad video with OpenArt.

[Open Plugins & MCPs](https://cursor.com/dashboard/plugins)

[Video 65](https://openart.ai/mcp/)

## Connect OpenArt to Kimi

1
### Install the OpenArt plugin

On [kimi.ai](https://www.kimi.ai/), open [OpenArt in the plugin store](https://www.kimi.ai/plugins?pluginId=19f7e230-5542-89e7-8000-00005199bf88) and install the plugin.

2
### Connect your account

Sign in with your **OpenArt account** to connect. No API key is needed.

3
### Start creating

Type **/OpenArt** in a Kimi chat to enable it. Then ask Kimi to make an ad video with OpenArt.

[Add OpenArt to Kimi ![Image 10](https://pageforge-56o.pages.dev/assets/mcp/kimi.webp)](https://www.kimi.ai/plugins?pluginId=19f7e230-5542-89e7-8000-00005199bf88)

## Connect OpenArt to Other MCP Agents

1
### Find the MCP Settings

Look for Connectors, Integrations, or MCP servers.

2
### Point It at OpenArt

Add a server with transport **Streamable HTTP** and the URL above. No API key, no extra config.

https://mcp.openart.ai/mcp

3
### Authenticate via OAuth

Sign in with your **OpenArt account** on first use. Credits and results stay tied to your account.

## Frequently Asked Questions

What is the OpenArt MCP?

MCP (Model Context Protocol) is an open standard that lets AI agents use external tools. Once connected, your agent can call OpenArt to generate images and video and return the results directly in your conversation.

How do I add OpenArt as a Claude connector?

In Claude desktop or on claude.ai, go to Customize → Connectors, click Add custom connector, name it OpenArt, and paste the server URL. Click Add → Connect and sign in with your OpenArt account. Claude then works as a [Claude AI image generator](https://openart.ai/mcp/claude-ai-image-generator/) and a [Claude AI video generator](https://openart.ai/mcp/claude-ai-video-generator/), so you can ask it to make an image or an ad video right in the chat.

Can I use OpenArt MCP in Cursor?

Yes. In the Cursor desktop app, open Settings → Tools & MCP and add a new MCP server named OpenArt with the server URL. If Cursor opens mcp.json, add it as the server's url. Click Connect and sign in with your OpenArt account, and OpenArt tools show up in Agent chats. For full setup steps, see the [Cursor MCP](https://openart.ai/mcp/cursor/) guide.

Do I need an API key?

No. Add the server URL in your agent's settings and sign in with your OpenArt account through OAuth. There are no keys to create, rotate, or leak.

What can my agent actually do?

Generate images and video, plan multi-shot videos with Smart Shot, discover available models, track results, upload reference files, check your account and credits, switch workspaces, and organize projects, all from the conversation. The tool list updates automatically as new tools ship.

Which image and video models can I use?

Image models include Nano Banana 2.1, Nano Banana Pro, GPT Image 2.5, GPT Image 2, Seedream 5 Pro, Wan 2.7 Image, Ideogram 4.5, and Grok Imagine Image 2.0. Video models include Seedance 2.5, Seedance 2.0, Wan 3.0, Kling 3 Omni, Veo 3.1, MiniMax H3, Gemini Omni 1.1 Flash, and PixVerse V6. Your agent can pick a model automatically or use one you name, and new models appear automatically as OpenArt adds them.

Does OpenArt MCP work on Team and Enterprise plans?

Yes. On managed workspaces (Claude Team/Enterprise or ChatGPT Business/Enterprise), OpenArt has to be added for the whole organization once before members can use it. In Claude, only an Owner or Primary Owner can do this: go to Settings → Organization settings → Connectors → Add and enter the server URL [https://mcp.openart.ai/mcp](https://mcp.openart.ai/mcp). In ChatGPT, a workspace owner or admin enables the OpenArt plugin for the workspace, and members then install it from chatgpt.com/plugins. Each member signs in with their own OpenArt account via OAuth. On personal plans, you can add OpenArt yourself. Once connected, generations spend the workspace's credits and results save to the workspace library so your team can pick up where you left off.

Can I use Character or Smart Shot through MCP?

Smart Shot works through MCP today. Your agent can preview the Shot Plan first, or plan and render the video in one request. Image generation, video creation, image-to-video, external image references, and your OpenArt library are also available. Character is on the roadmap.

How do I install and use OpenArt CLI?

Install the CLI, run openart login, and start creating from your terminal. See the complete setup guide on [OpenArt CLI GitHub](https://github.com/OpenArt-AI/cli).

Where can I find the latest OpenArt MCP and CLI feature updates?

Check our email announcements or our GitHub/MCP page, both are kept current with new feature releases and changelogs.

Which platforms and AI tools does OpenArt CLI support?

OpenArt CLI works on macOS, Linux, and Windows. You can use it with Claude, ChatGPT, Cursor, and other AI agents. It’s ideal for terminal-based workflows, automation, and batch creation.

How do I connect OpenArt to ChatGPT?

Go to chatgpt.com/plugins, search for OpenArt, click Install Plugin, and sign in with your OpenArt account. Then type @OpenArt in any chat and describe what you want, from a single image to a full video. Learn more about using it as a [ChatGPT AI video generator](https://openart.ai/mcp/chatgpt-ai-video-generator/).

Can I use OpenArt MCP in Kimi?

Yes. On kimi.ai, open [OpenArt in the Kimi plugin store](https://www.kimi.ai/plugins?pluginId=19f7e230-5542-89e7-8000-00005199bf88), install the plugin, and sign in with your OpenArt account. No API key is needed. Then type /OpenArt in a Kimi chat to enable it and ask Kimi to make an image or video. The plugin is currently available on Kimi's international site, kimi.ai.

How does pricing work?

Generations through MCP spend the same credits as if you're generating on openart.ai. Each generation costs credits based on the model and resolution, and your existing plan works without any extra setup.

Where do my generations go?

Everything your agent creates is returned in the conversation and saved to your OpenArt library, so you can keep iterating on openart.ai whenever you want a full canvas.

Can I upload an external image as a reference?

Yes. In Claude, OpenArt provides an upload widget so you can upload an image to OpenArt right inside the conversation and use it as a reference. You can also paste an image URL, which works in any client that supports it.

How does OpenArt MCP help with AI asset management?

It lets you browse, reuse, and create assets inside the active OpenArt workspace instead of treating every generation as a disconnected file. For teams, it also helps route work to projects and keep credit usage tied to the right workspace.

What if I have multiple MCP servers connected?

Just mention OpenArt in your prompt so your agent knows where to route the request. For example: "Use OpenArt to generate a 5-second product video" or "With OpenArt, create 4 image variations of this concept." This keeps the agent from guessing and makes results more predictable. Once OpenArt becomes your go-to for image and video, you can drop the name entirely.

Can I install the OpenArt CLI from a web browser?

No, the CLI install command needs to run in a coding agent's desktop app (like the terminal built into Claude Code, Cursor, etc.) or a local terminal on your computer, it can't be run from a web browser.
