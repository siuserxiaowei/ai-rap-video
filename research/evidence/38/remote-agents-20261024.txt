## Remote Agents FAQs

What are Remote Agents?
Remote Agents are AI agents from outside invideo, such as Claude, Codex or Cursor, that connect to invideo's editor over MCP. Each one edits the same timeline you do, under its own cursor, and you can edit at the same time.

What is the invideo MCP server?
It is invideo's timeline editor, available as a remote server over the Model Context Protocol (MCP), the open standard AI agents use to work with tools. Once connected, an agent like Claude Code, Codex or ChatGPT can open an editor, import media and edit the timeline while you watch in your browser.

Which agents and apps work with it?
Any client that supports remote MCP servers: Claude Code, Codex, Cursor, Hermes Agent, OpenClaw, Claude on the web and desktop, ChatGPT through its apps directory, and others. The server uses Streamable HTTP at mcp.invideo.io/mcp.

Do I need an invideo account?
Yes. You sign in with an invideo account, and you can create one during sign-in. Connecting does not need an API key: your client asks you to sign in when it connects.

How is this different from a text-to-video tool?
Your agent decides the edits, and invideo applies them as explicit changes to a timeline, such as cuts, clip placement, text and effects. The result is an editable timeline rather than a single rendered clip, and you can change any edit or restore an earlier checkpoint.

Can I edit while my agent is working?
Yes. You and your agent work in the same editor. You see its cursor and each edit as it happens, and you can make your own edits at any time.

What can I export?
A rendered video, or an editable project for Premiere Pro, Final Cut Pro or DaVinci Resolve. Exports come from a project saved to your invideo account.
