# AI Video Creation API

The AITuber API lets you create fully produced AI videos from a single API call. Send a script or topic, pick a voice and visual style, and receive a rendered MP4. Every video includes AI-generated visuals, natural voiceover, and word-synced captions. Build video creation into your app, automate content pipelines, or generate videos at scale.

[View API Docs](https://aituber.app/api/)

Integration
## Create Your First Video

One POST request to the AI Video Creation API creates your video. [Create an API key](https://app.aituber.app/dashboard/api-keys), then poll GET /videos/{id} until the status is completed.

 curl 

```
curl -X POST https://app.aituber.app/api/v1/videos/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "script": "5 mind-blowing facts about black holes",
    "inputType": "idea",
    "expectedDurationSeconds": 60
  }'
```

How It Works
## How It Works

From idea to finished video in three steps.

1

### Describe Your Video

Send a topic or full script. Choose a voice, visual style, and aspect ratio. The API handles the rest.

2

### AI Generates Everything

Visuals, voiceover, and captions are created and synced automatically. Poll the status endpoint to track progress.

3

### Download Your MP4

Export the finished video and get a download URL. Ready for YouTube, TikTok, Instagram, or any platform.

FAQ
## Frequently Asked Questions

How many videos can I generate per day?

There is no daily limit. Generation is only limited by your credit balance. A typical 60-second video with basic image quality costs around 30 to 50 credits.

Can I customize the captions?

Yes. Choose from multiple caption styles (wrap-1, hormozi, beast, noah, handwritten, subtitle, impact, pop, chronicle, cyber, grit, luxe, terminal) and control whether captions are enabled and their position (top, center, bottom).

What happens if generation fails?

Credits are refunded automatically for failed generations. Poll GET /videos/{id} to check the status. If it returns "failed", the errorMessage field explains what went wrong.
