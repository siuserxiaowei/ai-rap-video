GoEnhanceAI API Documentation

GoEnhanceAI offers cutting-edge generative AI models for video and image processing. Our API provides developers with powerful tools to create stunning visual content.
## [​](https://docs.goenhance.ai/#what-you-can-do-with-goenhanceai-api)

What You Can Do With GoEnhanceAI API

*   **Video to Video Transformation**: Transform videos using our state-of-the-art models
*   **Text to Image Generation**: Create images from text descriptions
*   **Face Swap**: Swap faces in images and videos with high precision
*   **Video Effects**: Apply various effects to enhance your videos
*   **Image to Video**: Convert still images into dynamic videos

## [​](https://docs.goenhance.ai/#billing)

Billing

Every generation endpoint returns the number of tokens it charged, alongside the task id:

```
{
  "code": 0,
  "msg": "Success",
  "data": {
    "img_uuid": "115f672e-e5c2-4699-96d1-dcb759155fe0",
    "cost": 5.82
  }
}
```

A few things worth knowing about `cost`:
*   It is measured in **tokens**, the same unit used in every price table on the endpoint pages. One token is $0.02.
*   It is the amount **actually charged**, not the list price. If a discount is active on your account, `cost` is already the discounted figure and will be lower than the endpoint page shows.
*   Tokens are deducted the moment a task is accepted, not when it finishes. If the generation ends in failure, the same amount is refunded automatically — you are never charged for a failed job.
*   The exact figure depends on the model and on the options you send. Resolution and duration are the usual drivers; see the pricing table on each endpoint page.

To check your remaining balance at any time, call [Get User Credits](https://docs.goenhance.ai/api-reference/credits/tokens).
