# AI Rap Video：研究综合草案

本文件在持续验收网站后更新。它是有边界的产品分析，不是实测生成效果排名。金额以 2026-10-23 采集的官网为准；未登录结账，未上传人物素材，未购买服务。

## 当前可确认的产品分流

对普通用户，首先要问“想得到什么”，再选择工具：

| 用户想要的结果 | 已读取的代表 | 工作流边界 | 产品启示（推断） |
|---|---|---|---|
| 用自己的照片演唱新 Rap | RapVideoGenerator、RapVideo.ai、RapReel | 照片、主题、场景与短片规格；是否包含原创音频应逐站确认 | 以人物和使用场景组织入口 |
| 替换已有 Rap 表演中的人物 | TryH3 | 视频参考或模板驱动，保留原片音频；不等同创作新歌曲 | 让模板音轨与原创音轨有清楚入口 |
| 为已有歌曲做剪辑和视觉 | CapCut、Media.io 专题 | 需要音轨、镜头、字幕与可能独立的口型步骤 | 保留“自带音轨”流程和时间轴需求 |

来源：[RapVideoGenerator](https://rapvideogenerator.com/)、[RapVideo.ai](https://rapvideo.ai/)、[RapReel](https://rapreel.com/)、[TryH3](https://tryh3.com/generator/ai-rap-video)、[CapCut](https://www.capcut.com/features/ai-rap-video-generator)、[Media.io](https://www.media.io/ai/explore/zone/ai-rap-video-generator)。

## 价格需要先统一规格

“注册免费”“每首约一美元”“每月低价”回答的是不同问题。免费额度可能只覆盖歌词或音频，付费包中的剩余点数也未必能刚好消费完。比较时同时记录一次实际付款、每条消耗、画质、时长、音频来源和点数到期规则。

目前有明确单次价格的 RapReel 可作为基准示例：Lite 8秒480p US$2.99，HD 12秒720p US$3.99，Pro 15秒720p US$5.99。该价格是官网显示，未验证生成结果或结账税费。[价格来源](https://rapreel.com/pricing)

RapVideoGenerator 的免费10点数只够30秒歌曲，视频起步100点数；用户需要先知道输出是音频还是视频。[来源](https://rapvideogenerator.com/pricing)

Airapvid 首页与表单的模型名称、结构化FAQ与价格表存在口径冲突。研究记录同时保存两者，后续集成不得自行选择较低数字作承诺。[来源](https://airapvid.com/)、[价格页](https://airapvid.com/pricing)

## 本轮开发优先级

以下是研究导出的建议，不是市场需求已验证的事实：

1. 先做研究目录、可追溯来源和透明规格比较，让选型能复核。
2. 做一个能保存与下载的创作 brief，把人物模式、场景、画幅、时长、歌词和语言定下来。
3. 渲染任务与 brief 分开；供应商未接入时明确不可用，不返回假视频。
4. 后续按当前官方 API 文档实现一个真实供应商 adapter，再用授权素材做质量与失败恢复测试。
5. 真实样本测试覆盖快语速、双人交替、手部遮挡、侧脸与中文；未测试前不给口型或画质排名。

## 方法限制

- 候选池来自搜索发现与相邻工作流扩展，为目的性样本，不能据此估算市场份额、营收或用户偏好。
- Codex 与 Gemini 使用相同公开页面语料做独立分析；这是分析复核，不是两份独立的外部证据。
- 网站文字和样片不证明实际成功率、等待时间、生成质量或退款履约。
- 价格可能依地区、登录状态、促销与付款周期变化；没有 API 文档只能写未发现，不证明没有接口。
- 相似价格或相似模板不证明网站属于同一运营主体，网站数量不等于独立公司的数量。
